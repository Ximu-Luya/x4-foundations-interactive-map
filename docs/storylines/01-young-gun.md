# 初生牛犊

## 开局定位

本体沙盒开局。它没有在参考图中标出的独享剧情，主要差异是从标准玩家总部任务线开始。

## 主要任务与分支

1. **玩家总部任务线**：完成标准总部任务，取得玩家总部。
2. **希望之歌任务线**：完成后与总部状态形成公共外交前置。
3. **Paranid 内战任务线**：进入 Paranid 选择点，可走统一或内战加剧方向；统一后还可能挑起对外战争。
4. **自由部族联盟任务线**：在 S 族选择点协助扎亚斯氏族获胜，或协助自由部族独立。
5. **创世计划任务线**：取得总部后可进入，与主线分支并行。

## 合流后的结局

总部与希望之歌都完成后，Paranid 和自由部族两条线可进入；若完成 Solborn Militia 后，还可进入隐秘计划与 Yaki 的宿命路线。结局取决于各自选择点，不由“初生牛犊”这个开局单独决定。
