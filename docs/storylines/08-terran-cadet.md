# Terran 军官学员

## 开局定位

`Cradle of Humanity` 的 Terran 开局。流程图显示它从暗夜民兵／特勤处路线进入人类版本的玩家总部任务，再与公共主线合流。

## 主要任务与分支

- 暗夜民兵／特勤处任务线。
- Terran 版玩家总部任务线 → 得到玩家总部。
- Solborn Militia 后续分出隐秘计划和 Yaki 的宿命。
- 总部取得后可进入创世计划；完成希望之歌后可进入 Paranid 内战、自由部族联盟。

## 主要结局

- 隐秘计划：无事发生、地球保护国向 Argon 与 Antigone 宣战、双方断绝贸易。
- Yaki 的宿命：清剿 Yaki、无事发生、Xenon 入侵太阳系、恢复 Yaki 贸易等结果。

> Terran 开场与 Solborn Militia 的具体任务先后在原图存在交叉关系；页面按“Terran 总部入口 → Solborn → 人类分支”的结构表达，具体触发时序仍待游戏内核对。
